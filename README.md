# √2 Ray CP 原型

把正方形 PNG/JPG 折痕图重建为 Oriedita 可读取的 `.cp` 文件。

本项目当前使用四条硬规则：

1. 内部线方向只能是 `22.5° × k`。
2. 四角和四边中点是固定免费起点；整张图最多再使用一个 `a+b√2` 核心参考点。
3. 此后只能从已有射线的精确交点或已有射线与纸边的交点继续发射，不再引入其他自由点。
4. 输出线段的端点来自上述派生节点，长度不能自由指定。

纸张边界写为 `.cp` 类型 `1`，红色峰线写为类型 `2`，蓝色谷线写为类型 `3`；不使用会被 Oriedita cAMV 排除的辅助线类型 `4`。

## 当前重建方法

程序分别使用有限射线、LSD 端点图和 Hough 端点图识别线稿。有限射线结果作为高精度骨架，另外两路只补充骨架尚未覆盖的线；最终方向统一为严格的 `22.5° × k`。

构造器先独立完成四角与四边中点能够推出的合法射线，再从剩余观测焦点中只选择一个 `a+b√2` 核心参考点。候选依次偏好中轴、对角线、纸边和普通内部位置；同类候选优先靠近正方形中心。接近完整直线的数量、双侧延伸程度以及 `a、b` 是否不超过 10 都只作为软偏好，不会单独淘汰候选。此后只允许精确射线交点和射线与纸边的交点继续传播；纸边交点是派生点，不是新的根号二种子。同一个观测焦点只能绑定一个精确节点，避免不同子线各自选择邻近交点而产生错开的平行线。

图像检测产生的自由端点会吸附到另一条已经证明存在的构造射线或纸张边界，无法解释的悬空线会被丢弃。

几何确定后，程序完全在本地从原图像素计算每一段折痕的红/蓝证据、覆盖率和置信度。强红与强蓝直接锁定；模糊折痕先暂判，再运行完整 cAMV。只有模糊折痕可以在 Maekawa 或 big-little-big 报错后被改色，每次修改后都会重新运行 cAMV。若没有同时改善 cAMV 且不违背像素证据的修改，程序保留剩余异常，不会为了得到“通过”而改动强证据折痕。整个流程不调用 AI、云服务或网络接口。

## 命令行测试

```powershell
python app.py --analyze input.png --cp output.cp --overlay overlay.png --reconstruction reconstruction.png
```

## 两种评测不能混用

开发时有正确 `.cp` 答案，必须直接比较预测 `.cp` 和参考 `.cp` 的矢量数据：

```powershell
python audit.py compare --prediction output.cp --reference answer.cp --json evaluation.json --svg difference.svg
```

它报告射线、有限线段长度和节点的精确率/召回率；几何指标仍与峰谷类型分开，避免把位置正确和颜色正确混为一谈。运行时没有正确答案，只能检查输出线是否有图片证据、角度是否合法、是否存在内部线头：

```powershell
python audit.py reliability --prediction output.cp --image input.png --json reliability.json
```

运行可靠性报告明确不衡量漏线、召回率或真实正确率。报告先执行 cAMV 的峰谷无关结构子集：内部节点偶数度、川崎角度和纸边拓扑；随后执行包含 Maekawa 与 big-little-big 的完整峰谷检查。结构与峰谷异常分别报告。这个分数是高权重但非绝对的完备性信号；真实折痕图本身可能不完备，所以不会仅凭它否决结果。两种报告不能互相替代。

## 当前边界

- 最适合数字绘制、外框完整、背景干净的正方形 CP 图。
- 低于 512 像素的纸面保持原始分辨率，不再为分析强制放大；这可避免一像素斜线被变成锯齿和假节点。
- 可以处理轻微旋转、短断口和一般 JPEG 噪声。
- 不支持自由角度线、曲线、严重透视、文字或圆；低饱和度、严重串色的峰谷线会保留为低置信度结果。
- 密集区域仍可能漏掉短线或产生少量错误连接；请先看叠加预览，再决定是否导出。
